항공사별 주간 운항

세부·보홀기타 필리핀

항공편별 상세(기종·좌석·현지 도착 시각 포함)는 공항 공식 스케줄과 합쳐 '항공편 상세' 탭에 정리했습니다.

읽는 법 · 유의사항

원문(항공사 예약시스템 형식)을 일반 용어로 바꿔 정리했습니다.

  • 시각은 모두 각 공항 현지 시각입니다. 필리핀은 한국보다 1시간 늦어, 표기상 차이보다 실제 비행이 1시간 더 깁니다.
  • 기준일 2026-10-15, 대부분 10/24까지 적용되는 하계 스케줄입니다. 10/25부터 동계 스케줄로 바뀌므로 업데이트가 필요합니다.
  • 기종은 대형(좌석 많음)·중소형으로 구분해 공급 규모를 가늠할 수 있게 했습니다.

        항공편 상세

        방향·한국 공항·필리핀 공항으로 거르거나 검색할 수 있고, 열 제목을 누르면 정렬됩니다. 한국 시각은 공항 공식 자료, 현지 도착·비행시간·기종은 원문 기준입니다. 귀국편 기종은 같은 노선의 짝편 기종을 따랐습니다(한국·세부퍼시픽 항공사는 편명−1, 필리핀항공은 편명+1 우선).

        클래스별 좌석 수

        운항 노선과 주간 운항 횟수는 '항공 공급 (원문)' 스케줄 기준입니다(요일 미확인 편 제외). 기종 이름을 누르면 표 아래에 그 기종의 좌석 지도가 열립니다(한 번 더 누르면 닫힘).

        좌석 지도

        좌석 지도

        클래스별 좌석 수와 좌석 배치(예: 3-3-3)로 그린 개략도입니다. 카드의 '좌석 수 표에서 보기'를 누르면 기종별 좌석 표의 해당 줄로 이동합니다. 왼쪽이 기수(앞쪽)이며, 화장실·갤리·비상구 위치는 반영하지 않았습니다. 좌석 번호까지 보려면 각 카드의 출처 링크를 열어 보세요. 화물칸 메모의 무게는 승객·수하물을 다 실은 뒤 남는 화물 여유를 추정한 값으로, 노선 거리·연료·실제 탑승률에 따라 크게 달라집니다.
